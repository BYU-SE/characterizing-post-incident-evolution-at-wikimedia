## Decisions


# Do we show artifacts? Are AIs different from IRs?
- IRs contain AIs. So there is a hard link there. Are they different artifacts?

Answer: The Action Item (AI) is a conceptual artifact, not a quantifiable one, and therefore should not be a node in your graph.

# Do we show AIs?

The Action Item (AI) is a conceptual artifact, not an actual artifact. We consider it part of an incident report.

# Do we show commits?

Code Reviews include commit messages and so we don't show them extra in this graph.



# What is on the graph:

Nodes, Edges connecting IRs, Tasks, Code Reviews.
